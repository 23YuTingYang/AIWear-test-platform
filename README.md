# AIWear Test Platform

AIWear Test Platform 是一个面向 AIWear 项目的统一测试仓库，集中管理功能测试、接口自动化、UI 自动化和接口性能测试四类测试资产。

## 项目简介

本仓库用于统一展示 AIWear 项目的测试实践，覆盖以下方向：

- 功能测试用例
- 接口自动化测试
- UI 自动化回归测试
- 接口性能测试

## 项目结构

```text
AIWear-test-platform/
├─ functional-test/     # 功能测试用例
├─ api-auto/            # 接口自动化测试
├─ ui-auto/             # UI 自动化测试
├─ performance-test/    # 接口性能测试
└─ README.md
```

## 模块说明

### 1. functional-test

功能测试用例文档与思维导图。

### 2. api-auto

接口自动化测试工程、测试数据与断言资料。

### 3. ui-auto

UI 自动化测试工程与页面测试用例。

### 4. performance-test

性能测试脚本、测试数据与结果附件。

## 技术栈

- Python
- Pytest
- Requests
- Playwright / Selenium
- JMeter

## 项目价值

- 统一整理功能测试、接口自动化、UI 自动化和性能测试资料
- 支持展示从功能校验到性能验证的完整测试链路
- 便于在 GitHub 和简历中呈现较完整的测试体系
