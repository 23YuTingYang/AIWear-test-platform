# AIWear Test Platform

AIWear Test Platform 是一个面向 AIWear 项目的统一测试仓库，用于集中管理接口自动化、UI 自动化和接口性能测试三类测试资产，便于项目展示、统一维护和简历呈现。

## 项目简介

本仓库将原先分散的三个测试仓库整合到同一个工程下，覆盖以下测试方向：

- 接口自动化测试
- UI 自动化回归测试
- 接口性能测试

通过统一目录结构、测试资料和项目说明，可以更清晰地展示 AIWear 项目的完整测试体系。

## 项目结构

```text
AIWear-test-platform/
├─ api-auto/            # 接口自动化测试
├─ ui-auto/             # UI 自动化测试
├─ performance-test/    # 接口性能测试
└─ README.md
```

## 模块说明

### 1. api-auto

接口自动化测试模块，主要用于核心业务接口的功能校验、参数校验、结果断言和批量执行。

当前目录下保留了原有接口自动化工程、测试资料和测试报告，便于继续维护和展示。

### 2. ui-auto

UI 自动化测试模块，主要用于关键页面和核心业务流程的自动化回归验证。

当前目录下保留了原有 UI 自动化工程、页面测试用例、页面源代码和测试报告。

### 3. performance-test

接口性能测试模块，主要用于关键接口的性能评估，包括响应时间、吞吐量、错误率等测试结果分析。

当前目录下保留了原有性能测试脚本、测试数据、结果文件和性能报告附件。

## 技术栈

- Python
- Pytest
- Requests
- Playwright / Selenium
- JMeter

## 项目价值

- 将接口自动化、UI 自动化和性能测试统一整合到同一个仓库中
- 支持从功能校验、页面回归到性能验证的多维度测试展示
- 便于统一管理测试代码、测试资料、测试报告和项目说明
- 更适合在简历和 GitHub 中呈现完整测试体系建设能力

## 说明

本仓库为统一展示版测试项目，保留原有三个测试方向的主要工程内容和资料，用于集中呈现 AIWear 项目的测试实践成果。
