# AIWear 接口文档

BaseURL：`http://139.199.222.234`

本文档用于快速查看当前接口如何请求、成功时返回什么、错误时返回什么。详细测试场景请查看 `AIWear接口测试用例.md`。

## 1. 通用说明

### 1.1 统一返回结构

```json
{
  "code": 200,
  "message": "成功或失败说明",
  "data": {}
}
```

常见业务状态：

1. `code=200`：请求成功
2. `code=400`：参数错误、请求头错误、业务校验失败
3. `code=500`：服务内部异常、JWT 解析异常或下游服务异常

### 1.2 鉴权方式

登录后接口使用 `Authorization` 请求头：

```text
Authorization: Bearer token-x
```

`token-x` 来自 `/api/user/auth` 成功响应中的 `data.token`。

## 2. 用户接口

### 2.1 发送验证码

- 请求方式：`POST`
- 地址：`/api/user/send-code`
- 请求头：`Content-Type: application/json`

请求示例：

```json
{
  "email": "2447005837@qq.com"
}
```

正确返回示例：

```json
{
  "code": 200,
  "message": "发送验证码成功",
  "data": {
    "sendTo": "***",
    "expireTime": 300
  }
}
```

错误返回示例：

```json
{
  "code": 400,
  "message": "邮箱不能为空",
  "data": null
}
```

### 2.2 统一认证

- 请求方式：`POST`
- 地址：`/api/user/auth`
- 请求头：`Content-Type: application/json`

账号密码登录请求示例：

```json
{
  "account": "Yang",
  "password": "Yyt1112"
}
```

邮箱验证码登录请求示例：

```json
{
  "account": "2447005837@qq.com",
  "verificationCode": "123456"
}
```

正确返回示例：

```json
{
  "code": 200,
  "message": "认证成功",
  "data": {
    "userId": 1,
    "username": "Yang",
    "email": null,
    "token": "token-x"
  }
}
```

错误返回示例：

```json
{
  "code": 400,
  "message": "用户名或密码错误",
  "data": null
}
```

### 2.3 退出登录

- 请求方式：`POST`
- 地址：`/api/user/logout`
- 请求头：`Authorization: Bearer token-x`
- 请求体：无

正确返回示例：

```json
{
  "code": 200,
  "message": "登出成功",
  "data": "登出成功"
}
```

错误返回示例：

```json
{
  "code": 400,
  "message": "缺少请求头令牌",
  "data": null
}
```

## 3. 图片接口

### 3.1 上传图片

- 请求方式：`POST`
- 地址：`/api/file/upload/image`
- 请求头：
  - `Authorization: Bearer token-x`
  - `Content-Type: multipart/form-data`

请求参数：

```text
file: 接口自动化测试/api_auto_test/testdata/images/人物女人.jpg
```

正确返回示例：

```json
{
  "code": 200,
  "message": "图片上传成功",
  "data": {
    "url": "https://example-oss/image.png",
    "fileName": "人物女人.jpg",
    "fileSize": 19700
  }
}
```

错误返回示例：

```json
{
  "code": 400,
  "message": "图片文件不能为空",
  "data": null
}
```

## 4. 记录接口

### 4.1 我的记录

- 请求方式：`GET`
- 地址：`/api/record/my`
- 请求头：`Authorization: Bearer token-x`

请求参数：

```text
action=merge
```

说明：`action` 可不传；传 `edit` 查询编辑记录，传 `merge` 查询合并记录。

正确返回示例：

```json
{
  "code": 200,
  "message": "查询成功",
  "data": [
    {
      "id": 2,
      "userId": 1,
      "action": "merge",
      "inputOssUrl1": "https://example-oss/person-image.png",
      "inputOssUrl2": "https://example-oss/cloth-image.png",
      "instruction": "把第二张衣服穿到第一张人物身上",
      "resultUrl": "https://python-temp/merge-result.png",
      "outputOssUrl": "https://python-temp/merge-result.png"
    }
  ]
}
```

错误返回示例：

```json
{
  "code": 400,
  "message": "缺少请求头令牌",
  "data": null
}
```
